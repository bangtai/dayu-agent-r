### 3. CR4 owner 语义核对

- **声明归属**：首页身份后必须是 `業績公佈 + 未附加限定的集团财务业绩摘要 + 期间表头 + 两列年份` 的连续结构；页首只允许空、括号或已支持的交易所免责声明+发行人头，其它前置说明不跳过（`hk_body_facts.py:14-24,143-149`）。
- **摘要作用域**：摘要到页末只允许数值行、币种单位行、被数值行引用且以同一指标名开头并闭合（恰一个句号且以句号结束）的附注；任何未归属说明立即失败关闭（`hk_body_facts.py:40-90`）。真实跨页反例正是由末行“以下引述上年度公告…”触发关闭。
- **主报表/宣告**：只看紧随物理页的页首匹配；主报表必须给完整日期并以 `(月, 日, 性质)` 与摘要一致；宣告必须是同发行人、完整董事宣告句且期间定义标签精确为 `本期`/`本期內`；页 2/3 不同 `(date, kind)` 判 CONFLICT（`hk_body_facts.py:25-37,150-176`）。
- **同源性**：身份码集合来自同一首页文本；issuer 绑定来自首页免责声明头与宣告句；年份只来自完整日期见证（不取摘要列/披露日），月日与性质来自摘要并与报表见证比对；冲突守卫与其判定使用同一 `matches` 数据，未在下游重算。未发现 fallback、`getattr`、兼容分支或下游补偿。
- **通用 owner / 过拟合检查**：规则未硬编码公司、source ID、年月日或具体财务指标；测试用动态 0987/2031 正例证明。收窄点（见 Res 1）全部是 fail-closed 的支持范围边界，不会产生错误事实，未发现以“无关指标/币种”换取通过。
