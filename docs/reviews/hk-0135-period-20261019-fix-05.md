## 根因、实际修复和有限边界

动机成立。fix-04 已关闭页循环及表体结构缺口，但摘要、表体标签和 pending 定义共用的名词门仍把未命中旧标记集的判断/关系/来源/用途句当作名词，因而授权 Facts。直接根因在正文事实 owner，不在 selector、仓储、生命周期或当前四官方原件。

只修改 `hk_body_facts.py` 的共享准入及必要定义解析：

- 在已有篇章/句级标记外，按有限谓词构造检查判断/表征（代表、反映、屬/係/乃/即）、关系（與…有關/無關）、来源（取自/來自/摘錄自等动词构造）及用途（列作、供…之用）。宾语可变；规则不包含完整反例句、历史词、公司、年月、指标或币种名单。所有原接受位置复用同一门，折行最终拼接也检查。
- 定义仅在开头消费 `指不包括` / `乃根據` 固定句框，其余名词参数共用上述准入；最终仍须原有单句定义语法闭合。允许句框不等于允许把新谓词句塞入参数。
- 保留“附屬”的修饰构词，及普通否定名词、名词化分组。裸 `上年度比較資料`、`上年度之比較數字` 可与当前完整见证共存；不因过去词或数值恰等于年份列拒绝。

没有改跨页框架、完整日期/身份见证、年份一致性、输入契约、来源绑定、公共/持久 schema 或生命周期。年列仍只校验完整日期，不从首列/MAX/披露日猜年。P-B 无文本限定且年列相容时，不能由外部旧页标签改期。

这是**已证实构造的有限词法/句法检查**，不是任意中文谓词/名词识别或外部真实性证明。未支持措辞仍可能未被区分，部分合法复合名词也可能保守降为 unknown；不宣称所有未知语言形式都能自动失败关闭。根/Fins README 已按实际边界修正类别级承诺，tests README 记录实际回归；分层/装配未变，不触发 `dayu/README.md`。
