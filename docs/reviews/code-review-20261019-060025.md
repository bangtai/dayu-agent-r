- **临时资源边界**: 父进程被 SIGKILL 时 `TemporaryDirectory` 输入可能残留；连续第二次 Task cancel 打断 `_close_extraction_handle` 时，外层 finally 会先删输入而 private close task 继续收口；`_cleanup_worker_input` 失败会以 cleanup typed 错误覆盖原始提取错误。均为边界路径，现有测试覆盖单次取消/崩溃/启动失败，不覆盖上述组合。
- **正文声明识别边界**: `parse_hk_body_pages` 以“页面内唯一一致的受支持声明”为准；若第 1–3 页只出现一条“本集團截至上一期间...綜合業績如下”而没有本期声明，理论上可能把上一期间当作本期（当前四份原件无此形态，且同时出现会 conflict）。属于计划支持范围外的残余误判风险，未取得真实反例，故未列为 finding。
- **未支持输入**: 简体“股票代码”写法、中文数字日期、扫描件、第 4 页以后声明、合订/多主体文档均按设计返回 unknown；计划已列为 later work unit。固定本机之外的平台/spawn/native 行为未验证。
