## CR4：声明归属与完整作用域

唯一 owner 现在采用封闭的公告结构，而非在全页任意匹配后排除几个反例词汇：

1. 首页身份必须位于已支持的公告头内；可接受裸身份头，或标准交易所免责声明及发行人头。未知前置说明不能当页眉跳过。身份后必须连续出现业绩公告、无附加限定的集团财务业绩摘要、年度或六个月期间表头及两列年份；年份列只验证结构，不据其先后推断本期年份。
2. 摘要到页末只能包含受支持的数值行、币种单位，以及被数值行明确引用、以同一指标名开头的完整定义附注。附注定义须闭合，独立说明不能被忽略；这样历史作用域不会在跨页时丢失。没有硬编码公司、source ID、年/月/日或财务指标名，附注归属来自摘要行本身。
3. 随后领先物理页必须从主报表完整日期，或同一发行人董事直接发布的完整宣告开始；不跨过未知段落去寻找引文内部的声明。宣告中的“本公司”必须绑定公告头的同一发行人，“本期/本期內”必须是完整期间定义标签，不能从“非本期/本期以外”等文字取子串。孤立摘要、表名、比较列或旧宣告自身的“本期”均不足以确认。
4. 主报表/宣告的月、日、性质必须与摘要期间一致；受支持连续报表的完整日期有冲突就关闭。日期年份来自完整日期见证，不来自摘要列、披露日期或偶然顺序。结构不足返回 unknown，不分配发布身份。

这收窄了正文支持语法，没有建设通用 PDF/NLP 平台。当前 grammar 的表格单位、数值行和附注形式之外保留 unknown，未声称理解任意自然语言限定或任意版式。
