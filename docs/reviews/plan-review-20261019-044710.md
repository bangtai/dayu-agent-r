## 6. Open Questions（均交实现/完整代码审核，不阻塞本轮）

1. `CnReportDiscoveryResult.__post_init__` 与 filing workflow 复用同一公共校验时，local witness 的“实际 bytes”具体由哪一窄输入携带。计划已要求“同一公共校验核读回 bytes”，但类型形状由实现者决定；代码审核须确认 prepared 与 local 两路都传入实际 bytes，而不是只核 witness 字段。
2. models 的封闭 `fiscal_year_source` 类型须覆盖既有标题 rebuild 值 `source_title_and_annual_end`、CN 现有值与新增正文值，避免标题 rebuild 因类型收窄而漂移。计划“保留现有 title/CN 路径值”已覆盖语义，代码审核核验构造点。
3. `dayu.runtime.interruptible_process` 是 asyncio 接口，而当前 `list_report_candidates` 为同步入口。正文提取由 Fins 编排时，同步/异步桥接与取消检查的精确接口形状未在计划定死，属实现细节；代码审核须确认不在运行中的 event loop 内错误使用同步桥、取消能及时收口。
4. `hk_report_date_source` 从“仅看 report_date”改为“显式消费来源”后，upsert/rebuild/processed 全部调用点的签名更新与值域一致性，交代码审核。
